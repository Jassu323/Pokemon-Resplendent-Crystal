# Review Evidence

For future feature scoping and prototype reviews, include relevant audio
recordings, screenshots, or short videos to support the user's manual
verification. Prefer clearly labeled production-versus-candidate comparisons
when behavior or presentation changes. Record timings in milliseconds and
display frames, and distinguish automated checks from listening/visual approval.

Keep prototype ROMs, private test saves, recordings, and generated test evidence
under `build/`. Do not change the production ROM or the player's main save
unless the user explicitly requests integration or save changes.
