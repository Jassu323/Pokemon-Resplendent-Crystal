This is a new version of [Pokémon Crystal Ultimate Fork](https://github.com/Jassu323/Pokemon-Crystal-Ultimate-Fork), which itself is a fork of [Major Agnostic's Pokémon Crystal Ultimate](https://github.com/MajorAgnostic/Pokemon-Crystal-Ultimate).  This version of Crystal uses fellowship-of-the-roms's [pokecrystal16](https://github.com/fellowship-of-the-roms/pokecrystal16) as a base, specifically the expand-move-ID branch, which is a 16-bit version of Crystal that expands the indices for the dex and moves to be 16-bit (roughly) instead of 8-bit.

Instead of trying to port the old version of that repo to use pokecrystal16, I decided to start it over entirely.  Like with the Fork of PCU, this version will diverge from it with my own changes.  Neither the Fork nor this version are truly intended to be ROM hack releases in their own right—the repos exist to document changes and allow others to use it if they so desire.  My personal usage is just to build it for my own interests and for some friends/family to play.
